## Post 1

I built Glassforce, a native macOS command bar for Salesforce. Option-Space opens a floating panel. You type a name, and Return opens the record in Lightning.

## Post 2

You choose the objects to search, including custom objects. The list can include Accounts, Contacts, Opportunities, Cases, Reports, and Setup pages. Fuzzy search stays under 50 ms.

## Post 3

Sign-in is OAuth with PKCE. Tokens stay in the Keychain. There is no telemetry. Salesforce data stays on the Mac. The license is MIT. Glassforce is not affiliated with Salesforce.
