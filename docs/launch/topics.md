# Suggested GitHub topics

Use this list when the repository becomes public. This file does not apply topics, and it does not call the GitHub API.

- `macos`. Glassforce is a native Mac app.
- `swift`. The app and the shared library are Swift.
- `swiftui`. The panel is SwiftUI.
- `salesforce`. Search and sign-in talk to a Salesforce org.
- `privacy`. The app sends no telemetry, and tokens stay in the Keychain.
- `oauth`. Sign-in is OAuth 2.0 with PKCE.
